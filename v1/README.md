# Versión 1 (sin código en este repo)

Primera versión del controlador: **dos pines transmitían heartbeats**, sin
comunicación serial.

No se conservó código fuente de esta versión. Si aparece, va acá. Lo único
que se sabe es el funcionamiento general:

- dos pines para el heartbeat;
- sin UART, sin comandos `CFG_*`, sin EEPROM;
- reemplazada por la v2, que sí usa serial.

Ver el historial en el `README.md` raíz.
